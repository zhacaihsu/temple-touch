# 四種法器 PWA（真實金剛鈴）

金剛鈴按一次播放一次鈴聲（由上傳的 MP3 裁切第一聲約 5.2 秒），其餘三種法器維持原音效。四組音量獨立 -10 至 +20 dB、預設 0 dB。音量設定保留在裝置。

更新方式：GitHub 切換到 `vajra-bell` 分支，上傳解壓後全部檔案到根目錄（`audio/bell.mp3` 要放在 audio 資料夾），Commit changes。Pages 仍選 `vajra-bell` 的 `/(root)`。網址不變。更新後關閉 PWA 再開啟。

注意：dB 為數位增益，非實際聲壓；+20 dB 可能過大，請先調低系統音量。金剛鈴聲音已加入離線快取。
