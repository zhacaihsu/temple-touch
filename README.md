# 四種法器觸控練習 PWA

木魚、鼓、鈸、金剛鈴，各佔四分之一畫面；直向手機改為 2×2。按圖片即發聲，各有 -10～+20 dB 的獨立數位音量調整，設定保存在此裝置。

**音量注意**：此處 dB 是相對於程式原始音訊的數位增益（0 dB = 不衰減；正值會放大訊號，可能失真），不是現場聲壓 dB SPL，也不保證設備的實際音量。請先調低平板系統音量再測試。

**聲音注意**：四種音效均為 Web Audio 合成音，金剛鈴是模擬金屬搖鈴聲，非真實法器錄音。

## GitHub Pages
將 ZIP 解壓後，將所有檔案直接上傳到 repository 根目錄（不要多包一層資料夾）。Settings → Pages → Deploy from a branch → main / (root)，儲存後等候部署。

更新後如果仍看到舊版，請重新整理或關閉再開啟 PWA，讓 Service Worker 更新。
